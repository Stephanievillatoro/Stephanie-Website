Featured Project

Building This Portfolio Website & Learning to Vibecode

A project completed for ISDS 3100: Information Systems Foundations at LSU, where we are learning to understand and work with AI — directing intelligent systems to build real deliverables through vibe coding.

Role Designer & Developer
Domain Web Development & Personal Branding
Technologies HTML, CSS, JavaScript, AI Tools
Timeline Fall 2026

1. The Starting Point

This website was built as a project for ISDS 3100: Information Systems Foundations in the E.J. Ourso College of Business at Louisiana State University. A central goal of the course is learning to understand and work with generative AI — not just using it, but directing systems to do work on our behalf. As future managers, we may never write software for a living, but we will increasingly guide technology that does: clearly specifying what a system should do, and judging whether its output meets the standard.

This project was my introduction to vibecoding, a modern approach to development where you collaborate with an AI agent by describing what you want in plain language, then reviewing, refining, and iterating on the results. Working in Google Antigravity IDE using a pair-programming approach, I acted as the navigator: deciding what the site needed to communicate to recruiters, directing the agent to build it, and checking every result before accepting it. I had no formal training in web development, so I learned by doing and by asking the agent to explain its choices along the way.

2. What I Built

The website you're viewing right now is the finished product. It includes:

  • A responsive homepage with sections for About Me, Skills, Experience, and Contact — all tailored to present my academic and professional background.
  • A dedicated resume page designed to give recruiters a comprehensive, printable view of my credentials, coursework, and certifications.
  • This project page documenting my process and what I learned along the way.
  • A polished visual design with a cohesive color palette, modern typography, smooth animations, and a fully mobile-responsive layout.

Technologies Used

HTML5 CSS3 JavaScript AI-Assisted Development Responsive Design Git & GitHub

3. The Vibecoding Process

Vibecoding is about more than just asking AI to write code. It's a skill that requires:

Clear Communication

Learning to describe design ideas, functionality, and structure in precise natural language so the AI can translate your vision into working code.

Iterative Refinement

Building piece by piece, reviewing what was generated, providing feedback, and refining until the result matched my standards.

Critical Evaluation

Not just accepting the first output, but understanding enough to recognize what works, what doesn't, and how to improve it.

Technical Literacy

Gaining a working knowledge of HTML, CSS, and JavaScript fundamentals through hands-on experience and AI collaboration.

4. Skills Gained

This project taught me far more than web development. The skills I developed are directly transferable to my career goals:

AI Collaboration
Learning to work with AI as a thought partner and productivity tool
Problem Solving
Debugging, iterating, and systematically improving toward a goal
Digital Literacy
Understanding how modern web technologies work together

5. Why This Matters

"The ability to work effectively with AI tools is not just a nice-to-have — it's becoming essential. Whether in accounting, information systems, or any professional field, knowing how to leverage technology to solve problems and communicate ideas is a skill that sets you apart."

Building this website showed me that the intersection of accounting and information systems isn't just academic theory — it's practical. The same analytical thinking I use in financial accounting applies to structuring a website, and the same communication skills I use as a bilingual tutor apply to vibecoding with AI. Every skill connects.
